# Contributing to The Future of Human Perception Podcast

This repo is the collaborative production hub for **The Future of Human Perception** — a podcast series exploring how augmented reality, spatial computing, and perceptual science shape (and are shaped by) the human experience.

## How to Contribute

### 1. Episode Research
Each episode has its own GitHub issue (#13 for Episode 1, #14 for Episode 2, #15 for Episode 3). These are the primary workplaces.

- **Add research findings**: link to relevant GitHub issues, papers, or articles
- **Suggest guests**: use the contributor table in each issue, or add your name if you're willing to be a guest or source
- **Surface debates**: what are the hottest open questions in the repos we track?

### 2. Audio & Editing
- Record segments and place them in `episodes/`
- Edit drafts and submit PRs with updated show notes

### 3. GitHub Community Tracking

We actively monitor the following repos for issues that illuminate the podcast's core questions:

| Domain | Repos |
|---|---|
| Web AR | `AR-js-org/AR.js`, `hiukim/mind-ar-js` |
| Mixed Reality | `microsoft/MixedRealityToolkit-Unity`, `microsoft/MixedRealityCompanionKit` |
| OpenXR / Standardization | `KhronosGroup/OpenXR-SDK`, `immersive-web/webxr`, `StereoKit/StereoKit` |
| Spatial Audio | `GoogleChrome/omnitone`, `leomccormack/Spatial_Audio_Framework`, `freeman-jiang/beatsync` |
| Streaming Latency | `polygraphene/ALVR`, `ValveSoftware/SteamVR-for-Linux`, `WiVRn/WiVRn` |
| Spatial Perception | `stereolabs/zed-sdk`, `artoolkitx/artoolkitx` |
| Neuroadaptive | `Caerii/OpenGalea` |

**Before filing an issue** in any of those repos, check if it maps to one of our three core questions:
1. *Latency*: How fast must a system respond before the brain accepts it as real?
2. *Spatial Audio*: How does sound conjure a 3D world from two speakers?
3. *Interfaces*: Where does the digital end and the physical begin in mixed reality?

### 4. Guest Outreach
- Use the **Guest Coordination Checklist** in `EPISODE-OUTLINE-MASTER.md`
- Tag potential guests in discussions
- Track outreach status with the `guest-research` label on each episode issue

## Code of Conduct

We follow the [Contributor Covenant](https://www.contributor-covenant.org/). Be respectful, cite sources, and stay curious.
